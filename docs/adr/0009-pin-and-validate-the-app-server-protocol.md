# Pin and validate the app-server protocol

The prototype will check in app-server schemas generated by its tested Codex CLI version, report the runtime version, and fail startup unless the initialization handshake and required protocol methods and fields validate. The app-server interface is experimental and its generated schema is version-specific, so silently accommodating an unknown Codex upgrade could corrupt lifecycle and delivery semantics; unexpected app-server exit stops the Mesh instead of triggering automatic recovery.
